## 迭代范围
1. **EX-4（缺陷）**：卡片标题未跟随分类——「树叶」分类下苹果卡片仍名为「苹果」，与封面（叶图）不一致。改为按分类派生：花→名+「花」（含花原名）、叶→一律 名+「叶」、果→`{ ginkgo:白果, pine:松果, lotus:莲蓬 }` 否则原名、全部→原名。
2. **EX-5（缺陷）**：详情默认部位未跟随入口分类——从「树叶」进入苹果却默认展示「花」。改为：入口分类有对应部位则默认选中，否则退回 `parts` 第一个部位。

## 验收标准（Sprint 8 Definition of Done）
1. PRD §13.5 增量验收标准 23~25 逐条通过。
2. `deriveCardTitle` 单测覆盖：花分类（含花原名 + 名称+花）、叶分类（一律名+叶）、果分类（银杏/松树/荷花特例 + 其余原名）、全部分类保持原名。
3. 详情默认部位跟随入口分类：「树叶」苹果→叶（`apple-leaf.jpg`）、「花朵」苹果→花、「果实」银杏→果（`ginkgo-fruit.jpg`）、「全部」苹果→花；换株后跟随当前分类。
4. 既有 TC 全量不回归（含 US-6 / US-7 与 Sprint 6 无滚动断言、Sprint 7 封面 / 字号断言）；接口契约、语料、路由不变。
5. 后端 `mvn test` + 前端 `npx vitest run` + `vite build` + `docker compose` 健康与两次导入幂等 + `npx playwright test` 全部退出码 0；全绿后 QA 放行，Master 执行 commit。
