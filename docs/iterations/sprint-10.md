## 四、验收标准（Sprint 10 Definition of Done）

1. PRD §15.5 验收 **34~40 逐条通过**。
2. **EX-4**：详情页「小知识」卡片有**可见标题文字「小知识」**（非仅 `aria-label`）；字号 ≥20px；无内容不渲染；新增标题后在 1024×768 与 1180×820 下长条目不溢出。
3. **EX-5**：动物 / 昆虫 / 恐龙横屏详情主图占可用高度 **≥80%**（现状约 61%）且完整不裁切；**植物详情（三部位）版式不回归**（部位按钮仍渲染、US-8 默认部位跟随分类仍成立、页面级溢出为 0）。
4. **EX-6**：首页植物板块首屏渲染条目数明显少于总量、可滚动加载至全量；加载不改变 `sort` ASC + `id` ASC 顺序语义；「共 N 种」口径与当前板块 / 分类一致；**回花园滚动位置记忆不回归**（增量加载下需保证恢复到原位置所需条目已加载）。
5. 既有 v1.0~v2.0 全部验收项**不回归**：US-3 / US-6 / US-7 / US-8 / US-9~US-12 行为不变；130 条目语料、6 分类、260 音频、266 图资产不变。
6. 平板横竖屏、1024×768 及 iPad 常见尺寸下正常；可操作元素热区 ≥56px；控制台无报错。
7. 门禁全绿：后端 `mvn test` 退出码 0、前端 `npx vitest run` 全通过、`vite build` 退出码 0、`docker compose up -d --build` 健康、导入两次幂等、`npx playwright test` 全通过；全绿后 QA 放行、Master commit。
