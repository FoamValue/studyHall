## 五、验收标准（Sprint 9 Definition of Done）

1. PRD §14.5 增量验收标准 **26~33 逐条通过**。
2. 站点标题为「自然小图鉴 / zì rán xiǎo tú jiàn / Nature Guide」。
3. 首页可切换 4 板块；植物板块下分类筛选（全部 / 花朵 / 树叶 / 果实）行为与既有语义一致；动物 / 昆虫 / 恐龙板块平铺列表。
4. 动物 / 昆虫 / 恐龙详情为**单图**，**不出现**部位切换按钮；植物详情部位切换（含 US-8 默认部位跟随分类）不回归。
5. 「小知识」卡片在各板块均可渲染；正文 ≤60 字、解释 ≤50 字；无内容不渲染。
6. 详情页中 / 英喇叭播放的是**预生成 mp3**（网络请求可见音频文件），同一文件在不同设备听感一致；mp3 缺失时该喇叭不渲染、**不**回退浏览器合成，其余功能正常。
7. 列表顺序 = `sort` ASC + `id` ASC，重复请求顺序稳定；不再依赖 Mongo 自然序。
8. 既有 v1.0~v1.5 全部验收项（§7 第 1~5、§9.4、§10.4、§11.4、§12.4、§13.5）**不回归**；既有 100 种植物内容与图片、路由、US-6 / US-7 / US-8 行为不受影响。
9. 平板横竖屏、1024×768 及 iPad 常见尺寸下板块导航与单图详情正常；可操作元素热区 ≥55px（现行 UI 规范为 ≥56px，以规范为准）。
10. 门禁全绿：后端 `mvn test` 退出码 0、前端 `npx vitest run` 全通过、`vite build` 退出码 0、`docker compose up -d --build` 健康、导入两次幂等（计数含新增条目与分类）、`npx playwright test` 全通过；全绿后 QA 放行、Master commit。
