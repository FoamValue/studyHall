1. PRD §9.4 增量验收标准 6~11 逐条通过。
2. 路由结构不变（`/` 首页、`/plants/:id` 详情），首页保留并继续作为入口。
3. 前端 vitest 用例同步更新并通过；E2E 增补「全屏进出」「三通道换植物」「首尾循环」用例并通过。
4. 后端 `mvn test` + 前端 `npx vitest run` + `vite build` + `npx playwright test` 全部退出码 0。
5. 以上全部满足后 QA 放行，Master 执行 commit。

## 风险与依赖
| 风险 | 应对 |
|---|---|
| 详情页需「有序邻居列表」，而详情接口只返回单株 | 复用 `GET /api/plants`（可带 category）；J-6 确认顺序稳定性与 Redis 缓存命中，**不改后端契约** |
| 左右滑与页面滚动 / 浏览器手势冲突 | 沉浸式态消除页面级滚动；对滑动做起止阈值判定，仅水平位移足够时才触发换株 |
| 全屏 API 在各浏览器（Safari/iPad）行为差异 | 全屏为增强项：不可用时按钮隐藏或降级，沉浸式态功能不受影响 |
| 门禁受影响用例 | `frontend/src/__tests__/PlantDetailPage.test.jsx`、`HomePage.test.jsx`、`frontend/e2e/smoke.spec.js` 需同步更新断言 |
