## 一、背景与目标

现状：首页以「8 个大按钮（SectionNav）」切换板块，下方直接渲染卡片网格；板块与内容之间没有「容器」这一层，缺少「取一本书、翻一本书」的实体感，对 3–6 岁幼儿不够具象。

目标：引入**书本集合**心智——每个板块 = 一本书；**首页 = 书架**；书的封面/版面以该板块主题的**简洁花纹**妆点。让孩子先「选书」，再「看书」。

**范围**：前端信息架构（IA）升级 + 8 张封面花纹资产；后端接口契约、内容语料、详情页版式**均不改**。

## 三、信息架构与页面规格

### 3.1 路由

| 路由 | 页面 | 说明 |
|---|---|---|
| `/` | 书架页（BookShelfPage） | 站头 + 两层书架 |
| `/books/:code` | 书内页（BookPage） | code ∈ 8 个板块 code；未知 code 走友好兜底 |
| `/plants/:id` | 详情页（不变） | 返回按钮指向 `/books/{section}` |

### 3.2 书架页（`/`）

- 保留站头三行：`rèn zhī xiǎo tú jiàn` / `认知小图鉴` / `Cognitive Guide`。
- 两层书架，层标题保留「自然认知」「认知启蒙」（沿用 `SECTION_GROUPS` 语义）。
- 每本书（`.book`）：
  - 封面：花纹平铺底 + 书名 / 拼音 / 英文 / 「N 种」；
  - 书脊：木色竖条（统一色系），书页厚度用 CSS 拟真；
  - 交互：`hover` 微抬升（≤4px）+ 点击进入 `/books/{code}`；
  - 可访问性：`role="link"` 或 `<button>` 语义、`aria-label="{书名}，共 N 种"`、热区 ≥56px。
- 加载/异常：分类接口失败显示「哎呀，出了点小问题，请稍后再试」；数量未就绪时先显示书名不含「N 种」，就绪后补显（避免布局跳动，建议用固定高度占位）。

### 3.3 书内页（`/books/:code`）

- 顶栏：「← 回书架」+ 标题「{板块名}书」；保留编号口径 **不显示**。
- 内容：沿用现有列表能力——「共 N 种」+ 卡片网格 + 首屏 16 / 步进 16 增量加载 + 哨兵。
- 视觉容器：轻量「书的内页」感（纸感底 + 书脊阴影），**不改变**卡片规格与字号。
- 滚动记忆：**按书隔离**，key 为 `sh:bookScroll:{code}` 与 `sh:bookVisibleCount:{code}`（替换现有全局 `sh:homeScroll` / `sh:homeVisibleCount`，避免多书串味）。
- 未知 code：显示「这本书还在路上哦」+ 「回书架」按钮。

### 3.4 详情页返回（改造点，仅文案与目标）

- 返回文案由「← 回花园 / ← 回动物世界 / ← 回昆虫角 / ← 回恐龙园 / ← 回字母乐园 / ← 回拼音角」统一改为 **「← 回{板块名}书」**（植物书 / 动物书 / 昆虫书 / 恐龙书 / 英文字母书 / 汉语拼音书 / 数字书 / 颜色书）。
- 点击返回 `/books/{code}`，并恢复该书滚动位置与已渲染条数。

## 四、封面花纹资产规范

| code | 母题（单一，重复） | 文件名 |
|---|---|---|
| plant | 一片叶子（含主脉） | `/images/covers/plant.jpg` |
| animal | 爪印（四趾） | `/images/covers/animal.jpg` |
| insect | 蝴蝶（对称简笔） | `/images/covers/insect.jpg` |
| dinosaur | 三趾脚印 | `/images/covers/dinosaur.jpg` |
| letter | 「Aa」字形 | `/images/covers/letter.jpg` |
| pinyin | 「a」字形 | `/images/covers/pinyin.jpg` |
| number | 「1 2 3」字形 | `/images/covers/number.jpg` |
| color | 实心圆点 | `/images/covers/color.jpg` |

- 规格：**1200×1200**、`.jpg`、可无缝平铺；单色线描（深墨/深棕），底为纸白/浅米。
- 密度验收：肉眼可见母题 ≤12 个/封面，留白 ≥60%。
- 兼容：若后续改由内联 SVG 实现，接口保持 `background-image` 不变，前端零改动替换。

## 五、验收标准（编号接 v2.6 §20.6，起 76）

76. 首页为书架：8 本书全部呈现，分「自然认知」4 本与「认知启蒙」4 本两层；1024×768 与 1180×820 下**页面级纵向溢出为 0**，无需滚动即可看全 8 本。
77. 每本书封面显示书名（中）、拼音、英文、「N 种」数量；不出现编号。
78. 8 本书封面花纹为对应母题（植物=叶、动物=爪印、昆虫=蝴蝶、恐龙=脚印、字母=Aa、拼音=a、数字=123、颜色=圆点），单色低密度平铺，可见母题 ≤12 个、留白 ≥60%；全部书底色统一，无「每本一个主色」。
79. 点击任一本书进入 `/books/{code}`，标题为「{板块名}书」，并提供「← 回书架」。
80. 书内页沿用「共 N 种」+ 卡片网格 + 首屏 16 / 步进 16 增量加载；植物书 206 条可完整加载到底。
81. 详情页返回文案为「← 回{板块名}书」，点击回到对应书内页，并恢复该书此前滚动位置与已渲染条数。
82. 多书滚动记忆互不串味：在植物书滚到中段、在动物书滚到顶部，分别往返后各自恢复正确。
83. 未知 code（如 `/books/unknown`）显示友好提示与「回书架」入口，不白屏、不报错。
84. 后端接口契约不变（`/api/categories`、`/api/plants?section=` 的路径、参数与响应结构不变）；内容总量不变（total 440 / 8 分类）。
85. 书单数据驱动：新增一条分类（含 `order`）后前端无需改码即可在书架上出现（以单测或 mock 证明）。
86. 既有 v1.0~v2.8 全部验收项（§7、§9.4、§10.4、§11.4、§12.4、§13.5、§14.5、§15.5、§16.5、§17.5、§18.5、§19.5、§20.6）**不回归**；后端 / 前端单测 / E2E 三层测试全绿。

## 六、非目标（本迭代不做）

- 不做真·翻页书页浏览（左图右文 / 左右翻页）。
- 不做抽书、翻书、书本展开等动画（列为 P2 观察项）。
- 不做书内章节目录（植物书不再分「果实 / 花朵 / 树叶」章节）。
- 不改详情页版式与字号（Sprint 17 已调）。
- 不改内容语料、图片、音频；不做手机端专项适配。
- 不做书架排序自定义 / 收藏 / 阅读进度。

## 七、影响面与测试迁移（QA 必读）

- **测试迁移（最大工作量）**：现有 E2E 中约 20 余条依赖「首页直接渲染卡片/板块按钮」（如 `loadAllCards`、板块切换断言），须整体迁移为「先进入对应 `/books/{code}`，再断言卡片」；`SectionNav` 相关断言改为书架断言。
- **单测**：`HomePage.test.jsx` 需拆分/重写为书架页与书内页两组用例；`PlantDetailPage` 返回文案断言更新。
- **样式**：新增书架、书本、封面花纹、书内页容器 4 组样式；需 UI 出规范（含 iPad 横屏 1024×768 / 1180×820）。
- **后端**：默认零改动；仅在 Q14 触发时才新增只读计数接口。
