## 1. 本迭代需求清单
1. **首页分类筛选**：顶部展示分类大按钮（花朵/树叶/果实 + 全部），点击筛选植物网格卡片（缩略图 + 中文名 + 拼音 + 英文名）。
2. **植物详情部位切换**：详情页单页展示一种植物，部位标签（花/叶/果）点击切换；缺部位不显示标签。
3. **部位内容**：图片 + 该部位三语名称（拼音/中文/英文+音标）+ 低龄化中文说明 + 典故（原文 + 一句白话解释）。
4. **内容扩容通道**：AI 将植物 JSON 写入 `content/plants/`，执行导入脚本即入库并直接展示，无需改代码。

## 3. 数据内容格式（约束，schema 细化归 J 设计文章）
- 植物 JSON 必含：id、分类、名称（拼音/中文/英文/音标）、部位（flower/leaf/fruit 可缺省）。
- 每部位含：图片路径（≥1 张简笔画，可附照片）、三语名称、低龄化说明、典故（可无）。
- 文案必须低龄化：短句、常用字、口语化。

## 4. 本迭代不做
TTS、问答、进度、账号、管理后台、手机专项（PRD §6）。
