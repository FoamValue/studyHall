| 编号 | 问题 | 冻结结论 |

| Q1 | 重绘范围 | **全站**：书架页 `/`、书内页 `/books/:code`、详情页 `/plants/:id`；三页共用同一套色板变量 |
| Q2 | 方案数量与选定方式 | UI 出 **3 套**完整配色方案（含整套变量 + 关键页面预览），**PO 按幼龄向与可读性推荐 1 套并冻结**，记录为 `P19-1` 待人工确认；人工后续可推翻重选 |
| Q3 | 换肤边界 | **只改 CSS 变量与规则**：不改 JSX 结构、组件层级、版式尺寸（书本 210×252 / 228×272、卡片网格、详情版式）、文案、路由 |
| Q4 | 封面 tile | 8 张封面**跟随选定色板重出**（`scripts/generate-covers.mjs` 改墨色/底色参数）；仍 1200×1200、渐进式 `.jpg`、母题与构图不变 |
| Q5 | 颜色硬约束 | 全站**单一主色系**（不再绿 + 木棕 + 奶油黄三系混搭）；正文对比度 ≥ **4.5:1**、大标题 ≥ **3:1**；幼龄向以低饱和暖色为主，禁止高饱和撞色 |
| Q6 | 动画范围 | **4 处**：书架→书内页（打开书本）、书内页→书架（关闭书本）、书内页→详情（翻开一页）、详情→书内页（合上返回） |
| Q7 | 动画形式 | **轻量渐变**：淡入淡出为基础，目的地可叠加轻微缩放（0.97→1）与 ≤12px 短位移；单段 **200~400ms**；`ease-out` 类曲线；**不做 3D 拟物翻书** |
| Q8 | 实现方式 | **优先纯 CSS**（页面容器入场 keyframes + 方向区分 class）；如 R 评估需退出动画，允许用 `document.startViewTransition` **渐进增强**（不支持时直切，不报错）；不引入动画库 |
| Q9 | 降级与测试 | `prefers-reduced-motion: reduce` 时**全部过渡降级为直切**（animation/transition 时长近似 0）；Playwright 统一 `reducedMotion: 'reduce'` 跑既有用例，新动效用例单测断言 |
| Q10 | 不回归清单 | 书架 8 本一屏零溢出、书本尺寸与四行文案、`共 N 种`、首屏 16 + 步进 16、滚动记忆按书隔离、详情返回文案与 href、单图详情版式与字号、`.plant-card` 规格与类名、控制台 0 报错 |

- **89**：8 张封面 tile 按新色板重出，仍为 1200×1200 渐进式 `.jpg`，母题构图不变。

- **91**：书内页→详情、详情→书内页过渡同 90 口径；滚动位置恢复与增量加载条数不因动画回归。

- **93**：三层测试全绿（后端 28 / 前端 vitest / E2E 全量），样式与动画断言按新方案同步。

## 四、风险与对策

1. **动画干扰 E2E 稳定性**：统一 `reducedMotion: 'reduce'`，避免时序竞态；新动效用例在单测中用假定时器或断言 class/样式值。
2. **换肤误伤版式**：Q3 硬约束——只改颜色与过渡，不改尺寸；QA 增加「关键尺寸不变」断言（书本 rect、卡片尺寸、详情主图占比）。
3. **封面重出导致 md5/体积变化**：保留资产规范（1200×1200 / q82 渐进式 / 单母题墨迹 ≤5%），门禁核对 8 张齐备且尺寸正确。
4. **对比度不达标**：UI 交付时逐色给出对比度数值，QA 抽验正文主色与背景。
