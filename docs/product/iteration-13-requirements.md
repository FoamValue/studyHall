## 三、需求明细

### 13.1 小知识字段（N2-1 / N2-2）
- 为 `content/plants/*.json` 每个缺失部位增补 `parts.{flower|leaf|fruit}.allusion`：
  - `text`：主文案（诗词名句 / 成语 / 谚语 / 常识句），≤60 字；
  - `source`：出处（可选）；
  - `explain`：一句低龄化白话解释，≤50 字。
- **不改**该条目的 `id` / `categories` / `sort` / `name` / `images` / `description` / 其它部位。

### 13.2 内容风格（面向 3–6 岁）
- 用词浅白、句式短、可朗读；不出现拉丁字母（沿用 description 口径）。
- 花 / 叶 / 果三个部位的小知识**各自与其部位相关**（如「果」讲果实特点或用途，「叶」讲叶片形态或诗句）；同一植物不同部位文案**不重复**。

### 13.3 落地方式（N2-3）
- 仅修改 `content/plants/*.json`，经 `node scripts/import-plants.mjs`（跑两次）导入；不改后端 / 前端 / 样式 / 资产。
