全站配色方案 v3 — 单一主色系 · 三套候选

现状为「绿 + 木棕 + 奶油黄」三套色系混搭：主色绿 #4CAF50 与书架木色 #C9A876、小知识卡黄 #FFF8DC / #F9A825 三者色相、饱和度、明度互不隶属，页面因此显得「配色奇怪」。本方案把每套候选收敛为一个主调色系， 木色 / 纸白仅作中性承载色，并统一调整其明度与饱和度以贴合主色系。所有对比度均为 WCAG 相对亮度公式实测值。

动画规范 — 4 处路由过渡（轻量渐变，不做 3D 翻书）

只动画 opacity 与 transform；动画挂在页面根容器（.bookshelf-page / .book-page / .detail-immersive），列表卡片不逐项入场。

过渡时长缓动opacityscaletranslateY标记
书架 → 书内页（打开书本） 320ms cubic-bezier(0.2,0,0,1) 0 → 10.97 → 1+10px → 0（自下轻抬） data-route-enter="shelf-to-book"
书内页 → 书架（关闭书本） 260ms cubic-bezier(0.4,0,1,1) 1 → 01 → 0.980 → -8px（向上收拢） data-route-exit="book-to-shelf"
书内页 → 详情页（翻开一页） 340ms cubic-bezier(0.2,0,0,1) 0 → 10.98 → 1+12px → 0 data-route-enter="book-to-detail"
详情页 → 书内页（合上返回） 240ms cubic-bezier(0.4,0,1,1) 1 → 01 → 0.990 → -6px data-route-exit="detail-to-book"

降级：@media (prefers-reduced-motion: reduce) 下取消全部位移与缩放（transform: none）， 入场仅保留 120ms 纯 opacity 淡入（防闪烁），退出即时；卡片 hover 的 translateY(-4px) 同时取消，只保留阴影 / 颜色变化。

UI 推荐：方案 A（温润纸感）

产品是给 3~6 岁的「图画书式图鉴」，书架 + 8 本书 + 书页 + 小知识卡，本质是把纸质绘本的体验搬到 iPad 上。A 的米纸底 + 深棕墨 + 一处柔橙朱砂，最贴合这个隐喻，也最容易让「木色书架」说服人：木色与主色同属暖棕色系家族，不再是与绿、黄并列的第三套色系。

B（清新自然）风险最低、与既有绿色语义衔接最顺，但木色被弱化后，「书架」的实体感会一起变弱；C（柔雾莫兰迪）最耐看，但低饱和雾蓝对幼儿的注意力牵引最弱，且与「图画书」气质偏离最远。

三套方案全部满足正文 ≥4.5:1、大标题 ≥3:1、封面墨/纸区间 1.4–1.8:1 红线；选定后由 PO 于 P19-1 冻结，UI 再出 U19-2 定稿章节。

说明：本页为纯 CSS 示意，未引用任何外部资源与网络图片；书本、封面花纹、卡片、详情照片位均为 div 绘制，仅用于比较色板关系，不代表最终像素还原。 对比度按 WCAG 2.x 相对亮度公式（sRGB 线性化，0.2126R+0.7152G+0.0722B）逐对实测。
